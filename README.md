# Academic OS — Modern Academic Workspace

An all-in-one workspace for students to organise subjects, coursework, readings, schedules, and deadlines with Slack, Google Calendar, and Firebase Cloud Firestore.

## Features
- **Daily Academic Dashboard**: Real-time study priorities and pending deadlines.
- **Subject Hub**: Track courses, faculties, and codes with color tagging.
- **Assignments & Readings**: Pre-reads, post-reads, and deliverables manager.
- **Schedule & Calendar**: Class timetables and event tracking.
- **Integrations**: Slack channel sync and Google Calendar connections.
- **Admin Panel**: User directory and role-based permissions management.
- **Firebase Backend**: Real-time Cloud Firestore & Firebase Auth (Google Sign-In + Email/Password).
